# 部署与排错

## 安装参数

| 参数 | 行为 |
| --- | --- |
| 默认 | 安装到 `%LOCALAPPDATA%\DragonCodexBoot-Community`，校验 Codex，备份/设置浅色外观，接入当前用户桌面和开始菜单 |
| `-InstallDir 'D:\Apps\DragonCodexBoot'` | 指定独立的新目录，支持空格、中文；不允许覆盖不属于本包的非空目录 |
| `-Offline` | 仅使用离线 ZIP 中官方 Node；缺失时失败，不偷偷联网 |
| `-Portable` | 仅准备运行文件，跳过 Codex 安装检查、外观和快捷方式修改；启动时仍需官方 Codex |
| `-NoShortcuts` | 保留原快捷方式，手动运行安装目录 EXE |
| `-NoAppearance` | 不调整 Codex 外观，请手动选浅色以获得对应效果 |
| `-Launch` | 安装完成后启动；首次接入可能正常关闭并重开未带壁纸参数的 Codex |

文件准备在源码目录 `.local/` 中进行；确认部署成功后可移除整个下载/源码目录，安装副本不依赖它。安装目录单独保存引擎、主题、视频和 Node，日志位于 `logs/`，资料位于 `skin/cdp-profile/`，原始外观和快捷方式备份留在本机。

当前只校验支持 Store 签名的 `OpenAI.Codex` 包及其 `app/ChatGPT.exe`。程序自动发现版本与应用 ID，若将来官方入口/结构发生变化，停止并更新适配，不能通过放宽身份校验解决。首次运行官方 Codex 会生成所需配置；未生成时安装会提示错误，可完成首次登录后重试。

## 原来的 Codex 打开没有动画

检查实际快捷方式目标，必须是安装目录 `DragonCodexBoot.exe`。桌面/开始菜单 `.lnk` 可接入，任务栏和开始屏幕已有固定项、应用列表、协议和直接 EXE 不属于同一入口。取消固定旧项，从新快捷方式重新固定。`.integration/report.json` 记录接入数量、错误和保留项。

## 安装失败

先看完整错误。源码安装下载依赖需要可访问 nodejs.org；断网使用 offline ZIP 和 `-Offline`。SHA-256 或签名不匹配时重新下载官方包，不要关闭校验。程序包清单不匹配时完整重解压；维护者编辑源码后需先更新清单。

如沙箱不能写入 LocalAppData 或快捷方式，请允许安装所需的本机写入；无需以管理员身份安装。不要因受限视图下快捷方式元数据为空就直接删除原入口。受管理的公司电脑如果禁止调试参数或执行脚本，该方案可能不适用。

## 动画结束仍未进入可操作窗口

查看 `logs/skin-handoff.log`、`logs/skin-watcher-error.log`、`qa/last-skin-ready.json` 与 `logs/launcher.log`。壁纸就绪需要真实渲染进程、正确的浏览器身份以及连续增长的解码帧数；网络登录、首次启动、CPU/GPU 或 Codex 更新都可能拉长冷启动。接续动画是等待期间的动态处理，不是启动已完成的证明。

Esc / 跳过按钮可跳过动画。连续失败时用安装目录 `Uninstall.cmd` 恢复，从官方 Codex 排查。不要使用开放到 `0.0.0.0` 的调试端口，不要关闭身份/签名检查。

## 恢复

运行安装目录 `Uninstall.cmd`。只恢复仍匹配安装记录的快捷方式；用户后来改过的链接保留。外观按安装时快照逐项恢复，保留后续发生冲突的外观修改与无关配置。恢复会停止经过 PID、开始时间及命令行验证的注入器，不会按 node.exe 名称批量杀进程。

若恢复报告错误，保留目录和备份后重试。保存工作并完全退出 Codex 后重新打开，清理当前已注入窗口；仅关闭窗口可能仍保留后台进程。程序文件与独立资料目录不会自动删除，确认后再自行移除该独立安装目录。
