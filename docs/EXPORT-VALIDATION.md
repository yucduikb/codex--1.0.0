# 导出验证记录

版本：`0.2.0-seamless.1`。验证日期：2026-10-18，Windows x64 / Windows PowerShell 5.1。

本次导出验证覆盖：

- 分发文件清单、字节长度和 SHA-256，PowerShell / JavaScript 语法，以及实际 C# 编译。
- 启动器 605 个几何用例、12 个固定窗口布局用例，9 个 IPv4 / IPv6 本机监听归属用例。
- 33 项隔离快捷方式备份与恢复断言，外观快照持久化和冲突保留。
- 实际引擎模块加载、当前 MP4 壁纸负载构建和主题契约。
- 源码安装识别本机官方 Codex，从 nodejs.org 下载固定版本压缩包，校验压缩包哈希、EXE 哈希及发布者签名后编译安装。
- 离线 ZIP 从独立目录解压，在带空格与中文的目标路径安装，验证安装副本文件、运行时、壁纸负载、启动器自检与恢复入口。
- 两份 ZIP 的白名单和 SHA-256；不包含个人账号、聊天历史、运行资料、日志或打包缓存。

源码安装测试禁用了外观和快捷方式修改；快捷方式及外观恢复使用隔离夹具验证。测试没有启动、关闭或修改当前正在使用的 Codex 安装。

这份记录说明导出与部署链路通过了隔离验证，不代替不同机器、显卡或未来 Codex 版本上的界面验收。实际动画、动态壁纸与窗口衔接仍应按 [TESTING.md](TESTING.md) 检查；不能据此承诺任意冷启动均无等待。
