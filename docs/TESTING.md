# 验收范围

自动检查：

```powershell
.\scripts\Test-Package.ps1
```

会校验所有分发文件的 SHA-256，解析 PowerShell/JavaScript，编译实际源码，执行 605 个几何用例和 12 个窗口位置用例，验证 IPv4/IPv6 端口真实归属，隔离测试快捷方式备份/恢复和外观冲突保留，并使用实际视频构建完整壁纸注入负载。不启动真实 Codex、不结束正在进行的任务。

完整离线包可用指定临时空目录做独立部署检查：

```powershell
.\Install.ps1 -InstallDir 'D:\Temp\Dragon deployment test' -Portable -Offline
```

检查 EXE、engine/runtime/node/node.exe、三段 MP4、theme.json、launcher.json 和 install-state.json，确认所有引用都指向这个独立目录。此模式不验证真实快捷方式和本机外观写入。

公开发布前，在另一台已安装官方 Codex 的 Windows x64 机器做界面验收：

1. 正常安装后，从桌面和开始菜单的 Codex 快捷方式启动。检查动画居中、声音、实时窗口衔接、主题和连续动态壁纸；结束后可立即操作已就绪的窗口。
2. 关闭窗口再从同一入口打开，确认窗口恢复和视频持续解码，不重复创建多个注入器。
3. 真正冷启动，再对照 logs/skin-handoff.log 的时间；慢机器可能用接续动画，不能以动画画面推断真实客户端就绪。
4. 安装后修改一个无关配置项，运行卸载恢复，确认保留该项并恢复受管理外观和原入口。
5. 任务栏旧图标重新固定后再测试；多屏、125%/150% DPI、较低分辨率和系统缩放需要各自验收。

先前本机修复已有热启动/冷启动界面验证，但耗时有波动。导出包的静态/隔离测试不构成对其他机器或未来官方版本的零延迟保证。
